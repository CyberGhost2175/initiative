# Прилёты / Отлёты — BI Product (демо)

Next.js-демо модуля приёма и обработки инициатив по БФТ «Окно прилётов / отлётов».

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) — редирект на `/showcase`.

## Маршруты

- `/showcase` — витрина (только свой отдел)
- `/mine` — мои инициативы
- `/queue` — очередь модерации
- `/analytics` — аналитика
- `/admin` — администрирование

## Что внутри

- Форма подачи инициативы с валидацией
- Витрина отдела, «Мои инициативы», очередь модерации
- Карточка со статусами, комментариями и сменой статуса
- Переключатель ролей (автор, куратор, owner, комиссия, руководитель, админ)
- Макеты аналитики и админки (фаза 2), задел AI (фаза 3)

Состояние демо хранится в памяти браузера (React context), без бэкенда.
